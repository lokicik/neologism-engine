# Personal prototype research

Phase 305 tests whether eleven explicit positive name anchors can supply a
small abstract spelling-shape energy over the frozen Phase 303
brief-conditioned whole-form pools. It is non-LLM, offline, deterministic, and
disconnected from production.

- `anchors.json`: user-provided positive anchors and frozen surface families.
- `PROTOCOL.md`: pre-result hypothesis, representation, selection, and gates.
- `evaluate.py`: deterministic development/sealed evaluator.

No mechanical result from this directory is a better-name claim. A passing
experiment still requires a new untouched absolute human evaluation.
