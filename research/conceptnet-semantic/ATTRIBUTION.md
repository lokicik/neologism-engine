# ConceptNet data attribution

Phase 297 may create an ignored local snapshot containing data from ConceptNet
5, compiled by the Commonsense Computing Initiative. ConceptNet 5 data is
available under the Creative Commons Attribution-ShareAlike 4.0 license from
https://conceptnet.io/.

The research code in this directory is project code. Any retained ConceptNet
snapshot or derived semantic index is a separate CC BY-SA 4.0 data artifact
and must preserve this attribution and the upstream data credits.
