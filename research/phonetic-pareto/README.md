# Phonetic Pareto research checkpoint

The first model-free consonant/vowel-stream crossover was tested and rejected.
It did not enter production and its one-off red Rust harness was removed after
the deterministic evidence was captured.

- [Frozen protocol](PROTOCOL.md)
- [Negative checkpoint](NEGATIVE-CHECKPOINT.md)

The checkpoint records the SHA-256 emitted by the executed protocol. The
archived Markdown differs only by repository-standard terminal-newline
normalization. Its historical command documents how the result was obtained;
the rejected example is intentionally not a maintained repository command.
