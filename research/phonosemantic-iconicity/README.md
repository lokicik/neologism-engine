# Multi-domain phonosemantic iconicity research

This isolated non-LLM lane tests whether human judgments of how a pseudoword
sounds across eight meaning domains can be recovered from a product-compatible
text representation. It changes no generator, ranking, WASM, web, storage, or
public type.

- [Frozen protocol](PROTOCOL.md)
- [Pre-inspection freeze](PRE-INSPECTION-FREEZE.md)
- [Source-unavailable checkpoint](SOURCE-UNAVAILABLE-CHECKPOINT.md)
- `refresh.py --refresh` is the only network-enabled entry point.

The source returned no public inventory, so modeling stopped. No model or
product claim exists.
